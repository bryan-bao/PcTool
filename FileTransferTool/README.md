# 局域网文件传输工具

电脑和手机、电脑和电脑之间,在同一个 WiFi/路由器下互传文件。带限速、实时速度、断点续传、接收确认。打包后是**单个 exe,双击直接出窗口,免安装**。

## 怎么用

1. 双击 `filetransfer.exe`,弹出窗口。
2. 手机连**同一个 WiFi**,用相机/浏览器**扫窗口左侧的二维码**,打开手机网页。
3. 手机网页选文件 → 发送;电脑窗口里会出现这个任务,点**同意**开始接收。
4. 收到的文件默认存在 **exe 同目录的 `received` 文件夹**(窗口左下角有显示);可点「更改位置」改到任意盘的目录。运行日志在同一目录的 `filetransfer.log`。

## 功能

- **限速**:左侧档位「全速 / 普通(10MB/s)/ 省流(1MB/s)」一键切换;每个任务还能单独填限速(KB/s);运行中改速度立即生效。
- **实时显示**:每个任务有进度条、百分比、实时速度、预计剩余时间。
- **断点续传**:大文件传一半断了,重新发同名文件会从断点接着传,不从头来。
- **接收确认**:别人发文件过来,需要你在窗口里点「同意」才会收,防止乱传。
- **电脑互发现**:点「扫描」能列出同一局域网里其它开着本程序的电脑。mDNS + UDP 广播(端口 52719)双路并行,结果去重,自动排除本机。
- **电脑互发支持文件夹**:给其它电脑发送时,既能选文件也能选整个文件夹,对端按原目录结构落盘;接收保存区有「打开文件夹」一键直达收到的文件。
- **发文件链接**:把文件/文件夹加进分享,得到一个固定的网页链接,发给对方(微信/QQ/邮件都行),对方浏览器打开是个下载页,想下哪个点哪个(文件夹整个打包成 zip),什么都不用装。随时可以再加或删掉条目,链接不变。

## 安全说明

- 扫码网址带一次性连接码(token),防止局域网内其他人乱连。
- 第一版局域网内走明文 HTTP(同一 WiFi 下风险可接受);远程传输与加密为后续版本。

## 开发

- 前置环境: Go 1.25+、Node.js、Wails CLI。若没有 Wails CLI,`build.ps1` / `build-installer.ps1` 会尝试用 `go install github.com/wailsapp/wails/v2/cmd/wails@latest` 自动安装。
- 实时开发:`wails dev`(热重载)。
- 打包单 exe:`wails build`,产物在 `build/bin/filetransfer.exe`。
- 一键打包 Windows 安装包:双击 `build-installer.bat`,产物在项目根目录 `FileTransferSetup.exe`。
  - 命令行也可运行 `.\build-installer.ps1`。
  - 第一次打安装包需要 NSIS;脚本会优先用 `winget` 自动安装,没有 `winget` 时按提示手动安装。
  - 脚本默认设置 `GOPROXY=https://goproxy.cn,direct` 和 `NPM_CONFIG_REGISTRY=https://registry.npmmirror.com`,方便国内网络拉依赖。
- 跑测试:`go test ./...`。

## 项目结构

- `internal/netinfo` 取局域网 IP / 可用端口
- `internal/ratelimit` 两级令牌桶限速
- `internal/transfer` 任务模型 / 断点续传 / 任务管理 / 速度采样
- `internal/qrcode` 二维码
- `internal/server` HTTP/WS 服务、上传下载、接收确认、手机网页
- `internal/discovery` 局域网发现(mDNS + UDP 广播双路)
- `app.go` / `main.go` Wails 装配
- `frontend/` 桌面窗口界面

## 远程传输(配合 Tailscale)

两台设备不在同一 WiFi 下也能传:借 Tailscale 把两台拉进一个虚拟局域网,再用本工具直传。

一次性准备(两台都做):
1. 装 Tailscale(tailscale.com),两台用同一账号登录
2. 记下对方的 Tailscale 地址(`100.x.x.x`)

传文件:
1. 两台都运行 `FileTransfer.exe`
2. 发送方在「远程发送」区填对方 `100.x.x.x` 地址,端口默认 **52718**
3. 「选文件发送」→ 对方窗口出现接收任务

要点:窗口会显示「本机地址」(对方就填这个);首次连接要在 Windows 防火墙提示里点「允许」;端口默认 52718,被占用会自动换(看对方窗口的本机地址)。

## 发文件链接(对方什么都不用装)

1. 窗口里「发文件链接」区,点 **＋ 文件**(可多选)或 **＋ 文件夹**,把要分享的东西加进来。
2. 不管加多少次,**都共用同一个链接**;点**复制链接**,把网址发给对方。
3. 对方用任意浏览器(手机/电脑都行)打开网址,看到一个列表页:文件点「下载」,文件夹点「打包下载」(整个 zip 拿走);你的窗口里能看到每个下载的进度,也吃全局限速。
4. 列表里每个条目后面有 **✕**,点了就从分享里移除,对方再打开页面就看不到它了。

要点:
- 下载期间**本程序要一直开着**;程序一关,链接就失效(重开也是新链接)。
- 对方得**能连到你这台电脑**:同一 WiFi 直接用;不在一起就两边都连好 Tailscale,用「复制远程链接」那条(装了 Tailscale 才会出现)。
- 链接带 16 位随机串,外人猜不到;大文件支持断点续传(zip 打包除外)。
- 文件夹在页面上只显示一行(名字 + 几个文件 + 总大小),不会把里面的内容铺出来。
