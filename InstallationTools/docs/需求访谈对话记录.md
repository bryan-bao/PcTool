## 核心洞察（用户点透的关键事实）

桌面上的图标分三类，重装后命运完全不同：

1. **快捷方式 → 本体在 D/E 盘**：重装 C 盘动不到本体，**还原快捷方式就能用** ✅
2. **快捷方式 → 本体在 C 盘**：重装后本体没了，光还原快捷方式是死图标 ⚠️（只标记，不替装）
3. **桌面上的真实文件/文件夹**：重装 C 盘会全没，需备份（用户勾选）

> 时间顺序铁律：「桌面上有啥」必须在**重装之前**采集保存到不会被清空的地方（D 盘/U 盘）。

## 确定的方案要点

- **形态**：在能进系统的 Win11 里运行的 PowerShell + WPF 图形工具，不做启动盘。
- **两步走**：① 重装前备份（扫描+拷贝到安全位置）② 重装后还原（清单勾选）。
- **重装**：两档（重置此电脑 / 镜像全新装），第一版先把"重置"档做扎实。
- **C 盘失效软件**：只标记，不自动装。
- **系统优化**：装后做一批可勾选的安全优化项。
- **五大模块**：桌面扫描器 / 备份器 / 重装执行器 / 还原器 / 系统优化器。

详细设计见同目录 `设计方案-预览.html`。
