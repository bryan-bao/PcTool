背景 & 目标

现在的「镜像装机」只会挂载扫描 images\ 里的本地 ISO，本地缺镜像就只能提示"没有镜像"；也不会按目标版本智能选装法。而且降级引导让用户去跑 MediaCreationTool_22H2.exe，可这文件压根不在目录里 —— 引导落空。

目标：点「镜像装机」→ 选 Win11/Win10 × 家庭版/专业版 → 工具按"目标 vs 当前系统"自动选最合适的装法；需要的官方工具/镜像 先找本地、缺了才用已核实官方直链稳妥下载。
承接：工作区里未提交的 Get-WindowsCatalog / Find-LocalIso / Get-IsoDownloadUrl 是前身。本设计保留前两个、改造 Get-WindowsCatalog、删除 Get-IsoDownloadUrl（Fido，改用官方制盘工具）。

四条路线（核心规则）

目标 vs 当前版本路线值怎么装要的东西 / 本地没有时
升级 ↑家庭版 upgrade-exe 官方"易升"exe，原地升级保留文件 tools\ 易升 exe → 没有就下载到 tools\
升级 ↑专业版 upgrade-iso 本地 ISO 的 setup.exe，原地升级保留文件 images\ 对应 ISO → 没有就下制盘工具做盘
同版本 =任意 reinstall-iso 本地 ISO setup.exe 重装 同上：images\ ISO → 缺了下制盘工具
降级 ↓任意 downgrade-usb U 盘装，弹现有小白引导 tools\ 制盘工具 / images\ ISO → 缺了下到 tools\
为什么这么分：① 易升 exe 只能升不能降，所以降级一律走制盘 U 盘，不分家庭/专业。② 升级按你定的规则：家庭版→exe（沿用当前=家庭版）、专业版→ISO（本地 Pro ISO 能原地升到 Pro）——正好对上本地现状：images\ 现有 Win10/Win11 ISO 都是专业版。

模块改动 · ImageManager.psm1

改 Get-WindowsCatalog

返回 4 项：Title + Major(11/10) + Edition(Home/Pro)。去掉 FidoWin。

新 Get-ReinstallRoute 纯逻辑·全测

入参 目标Major/目标Edition/当前Major → 返回 4 个路线值之一。

新 Get-OfficialToolUrl 可测

Kind ∈ {Win11Assistant, Win11MCT, Win10MCT} → 返回对应 URL；未知抛错。

新 Save-OfficialTool 稳的下载器

先找本地、缺了才下；TLS1.2 + 跟随跳转 + 重试3次 + 下完校验大小；全败抛带官网地址的错。

保留 Find-LocalIso

按文件名匹配主版本，给 upgrade-iso/reinstall-iso 找本地 ISO。

删 Get-IsoDownloadUrl

Fido 路线弃用（日志一直 NO_FILE），连测试一起删、移出导出。

Get-ReinstallRoute 逻辑

条件返回
目标 > 当前 且 家庭版upgrade-exe
目标 > 当前 且 专业版upgrade-iso
目标 == 当前reinstall-iso
目标 < 当前downgrade-usb

界面改动 · MainWindow.ps1

  • 版本来源从 Get-AllImageEditions（挂载扫描）改成 Get-WindowsCatalog，弹 4 项菜单。
  • 选完算 route = Get-ReinstallRoute …，按四条路线分支执行（见上表）。
  • 所有"装机"动作仍受 备份守卫约束：没有 manifest.json 一律阻止（沿用 Test-BackupReady / Invoke-ImageInstall 内置守卫）。
  • 降级仍复用 Show-DowngradeGuide，但第 2 步文案改成指向实际下载到的制盘工具路径，修掉现在引导落空的洞。
  • UI_SELFTEST / UI_SHOT 烟测保持能过。

错误处理 & 测试

下载失败不静默：Save-OfficialTool 抛清晰错误 → UI 弹框 + 给官网手动地址兜底。
找不到本地 ISO 且用户拒绝下载：状态栏回"就绪"，不动系统。
硬件要求（TPM/x64/9GB）：交给微软官方 exe 自检，工具不重复判断。
