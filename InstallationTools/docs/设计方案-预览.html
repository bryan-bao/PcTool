① 这是个啥

一个在 能正常进系统的 Windows 11 里运行的带界面工具(不做 U 盘启动盘)。核心解决一件事:重装系统会清空 C 盘(桌面也在 C 盘),重装后桌面就空了、东西全没了。这工具帮你在重装前先把桌面"记下来 + 备份好",重装后再列个清单让你挑着还原,不要的就顺手清理掉。

核心结论:工具分两步用——重装前先跑"备份"(存到 D 盘/U 盘,不会被清),重装后再跑"还原"(勾选列表)。一前一后,缺一步就白搭。

④ 模块划分

整个工具拆成 5 个各管一摊、能单独测的模块:

模块干啥关键点
1. 桌面扫描器
备份阶段		 扫描桌面(当前用户 + 公共桌面)所有 .lnk 快捷方式和真实文件,解析每个快捷方式指向的目标路径 判断目标在 C 盘还是 D/E 盘;区分快捷方式 vs 真实文件
2. 备份器
备份阶段		 把扫描结果写成清单(JSON),把要备份的快捷方式和文件拷贝到安全位置(D盘/U盘) 安全位置不能在 C 盘;大文件让用户勾选;留校验信息
3. 重装执行器
高风险		 提供两档:① 调用系统"重置此电脑";② 引导用镜像全新装 重装前强制确认 + 检查备份是否已完成;镜像档复杂,优先把"重置"档做扎实
4. 还原器
还原阶段		 读清单 → WPF 复选框列表 → 用户勾选 → 还原快捷方式和文件;失效项做标记 本体在C盘的标红"需重装";校验快捷方式目标是否还在
5. 系统优化器
还原后		 一批可勾选的优化项(关多余自启、显示文件后缀、电源计划等) 每项独立可选;只做安全、可逆的;具体项后续细化
主界面就三个大按钮:【1 备份桌面】 → 【2 重装系统】 → 【3 还原 + 优化】,顺着点就行。

⑤ 备份数据长啥样

备份清单用一个 JSON 文件记录,大概结构(示意):

字段含义例子
name图标显示名"微信"
type类型shortcut(快捷方式) / file(真实文件)
target快捷方式指向哪D:\Program Files\WeChat\WeChat.exe
targetDrive本体在哪个盘D(能救活) / C(会失效)
status还原可行性可还原 / 需重装
backupPath备份文件存哪了E:\InstallationTools\backup\...
好处:清单和备份文件都在 D/E 盘,重装 C 盘动不到它们,还原时直接读。

⑥ 风险与兜底

风险1 · 重装是不可逆的:一旦重装,C 盘没备份的全没。
兜底:重装按钮加"是否已完成备份?"强制确认;没检测到备份清单就拦着不让重装。
风险2 · 镜像全新装复杂且危险:涉及镜像、引导、分区,容易出事。
兜底:第一版先把"重置此电脑"档做扎实,镜像档作为进阶,做好充分提示,甚至第一版先只做引导不全自动。
风险3 · 快捷方式指向的盘符变了:U 盘/移动硬盘重插后盘符可能变,导致目标找不到。
兜底:只对固定内置磁盘(D/E)判"可还原";还原时再校验一次目标是否真的存在,不在就标记。
风险4 · 备份存到 U 盘但还原时没插:
兜底:还原前检查备份位置在不在,不在就提示插上。
安全原则:优化项只做安全、可逆的;所有破坏性操作(重装、清理)动手前都二次确认。
