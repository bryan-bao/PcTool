# 磁盘清理工具

Windows 桌面磁盘清理工具，PowerShell + WPF 编写，绿色免安装。

## 使用方法

双击 `一键启动.bat` 即可（会请求管理员权限）。

## 功能

- 系统临时文件清理
- 回收站清理
- 浏览器缓存清理（Chrome / Edge）
- 大文件查找（带「多久没用」提示）

删除一律「扫描 → 勾选 → 确认」，普通文件删到回收站可找回。

## 三档安全标记

- 🟢 **可放心删**：系统临时文件、回收站、浏览器缓存等公认垃圾，默认勾选。
- 🟡 **建议确认**：大文件且较久没动过（如「8个月没动过」），默认不勾选。
- 🔴 **谨慎**：大文件但最近还用过，默认不勾选，提醒别误删。

## 给别人用

整个文件夹拷过去，双击 `一键启动.bat` 即可，对方电脑无需安装任何东西
（Windows 自带 PowerShell）。

## 开发与测试

测试用 Pester 5：

```powershell
Invoke-Pester -Path .\tests -Output Detailed
```

源码文件（`.ps1` / `.psm1`）需保存为「带 BOM 的 UTF-8」，否则
Windows PowerShell 5.1 会按 GBK 读取导致中文乱码。

## 常见问题

- **杀毒 / SmartScreen 拦截 bat？** 选择"仍要运行"。脚本是纯文本，可右键编辑查看。
- **没有管理员权限？** 仍可清理浏览器缓存和用户临时文件；系统级目录可能跳过。
- **删错了怎么办？** 普通文件在回收站里，去回收站还原即可（除非你又清空了回收站）。
