这是什么

一个 Windows 桌面小工具，帮你把磁盘上没用的垃圾、缓存、超大文件、占地的整个文件夹找出来，确认后一键清掉，主要用来给快满的 C 盘腾空间。

三个让你放心的设计： ① 删的东西全部进回收站，删错了能还原； ② 扫描在后台跑，界面不卡，随时能取消； ③ 每一项都标了安全等级（能不能放心删），危险的默认不勾。

它怎么帮你判断"能不能删"

对系统垃圾/缓存这类，它知道删了系统会自动重建、没有副作用；对你自己的大文件/大文件夹，它会看"多久没动过""在什么位置"，给出建议，但最终删不删由你勾选决定。

怎么启动

  1. 在项目文件夹里找到 一键启动.bat，双击它。
  2. 会弹出一个 UAC 管理员授权窗口（蓝色的"是否允许…"）——点"是"。
    为什么要管理员 系统垃圾、更新缓存、日志这些放在受保护的系统目录里，没有管理员权限删不动。
  3. 稍等一两秒，主界面就出来了。
不想用 .bat 的话：也可以手动用管理员身份打开 PowerShell，运行项目里的 src\Start.ps1（启动参数要带 -STA）。一般直接双击 .bat 最省事。

能清理哪些东西

顶部一排可勾选的类别，绿色那几类默认就勾上了（放心删），后面三类风险高一些、默认不勾。

类别这是什么删了有什么影响安全等级默认
🧽 系统临时程序运行时产生的临时垃圾文件不影响使用，系统之后会自动重建可放心删✅ 勾
🗑 回收站你之前删进回收站的东西清空 = 彻底删除、无法再找回，先确认里面没想留的可放心删✅ 勾
🌐 浏览器缓存浏览器为了打开网页更快存的临时文件不影响账号登录和收藏，下次访问网页稍慢一点点
注意 清理时会自动关掉 Chrome / Edge		可放心删✅ 勾
♻️ 更新缓存Windows 下载更新时攒下的安装包装完就没用了，需要时系统会自动重下可放心删✅ 勾
💥 崩溃转储程序/系统崩溃留下的诊断文件（含蓝屏 MEMORY.DMP）普通使用用不上可放心删✅ 勾
🖼️ 缩略图缓存文件夹里图片、视频的预览小图缓存下次打开文件夹会自动重建可放心删✅ 勾
📜 系统日志Windows 各种运行日志不影响使用（正在占用的会自动跳过）可放心删✅ 勾
📦 大文件 >100MB单个超过 100MB 的文件（视频、镜像、安装包等）是你自己的文件，确认不用了再删；删后可在回收站找回建议确认 / 谨慎不勾
🗂️ 大文件夹 >100MB常用位置里体积大的整个子文件夹连里面所有文件一起删到回收站，可找回。详见下一节建议确认 / 谨慎不勾
🗂️ Windows.old系统升级后保留的旧版本备份，常有 10~20GB⚠ 删了就无法再回退到升级前的旧系统建议确认不勾
扫"大文件"还得先勾磁盘：大文件是按你顶部勾的磁盘去翻的，所以要先勾盘。大文件夹则固定扫几个常用位置（见下一节），不看你勾哪个盘。

安全标记怎么看

结果列表里每一行左边有个彩色小胶囊，告诉你这东西删起来有多大风险：

标记含义典型例子
可放心删系统垃圾/缓存，删了没有副作用，系统会自动重建临时文件、浏览器缓存、缩略图缓存
建议确认是你自己的东西，或者比较久没动过；删之前自己确认一下很久没用的大文件、下载夹里的大文件夹
谨慎最近还在用，或者是已安装程序的目录；删前三思这几天改过的大文件、Program Files 里的程序目录
绿色的会默认勾上、排在列表最前面；黄色和红色默认不勾，要你自己决定。

大文件 vs 大文件夹（重点）

这两个容易搞混，但解决的是两类不同的问题：

📦 大文件 >100MB

找单个超过 100MB 的文件。适合揪出某个忘了删的大视频、大镜像、大安装包。

范围：你顶部勾选的磁盘，整盘翻。

删除：删那一个文件。

🗂️ 大文件夹 >100MB

找体积大的整个文件夹——哪怕里面全是小文件堆起来的也能发现。适合清掉卸载残留、下载解压的整个目录。

范围：只扫"常堆东西的地方"（见下）。

删除：连里面所有东西一起删到回收站。

为什么要有"大文件夹"：只删一个大文件，会把一个目录删得残缺、里面的小文件还在、没清干净。"大文件夹"是以整个文件夹为单位来清，干净利落。

"大文件夹"会扫这些位置

下载、桌面、文档、AppData\Local、AppData\Roaming、ProgramData、Program Files（含 x86）。这些是安装包、缓存、软件目录最容易堆积的地方；像 C:\Windows 这种系统目录不会被当成可删文件夹列出来，避免误删一大片。

⚠ Program Files 里的目录会标红：那是已安装的程序，更稳妥的做法是去"设置 → 应用"里正常卸载，直接删可能留残余。确实要删也会进回收站、能还原。

排序规则

默认顺序

列表默认按这个优先级从上往下排，最该处理的浮在最顶：

flowchart LR
  A["① 已勾选
(绿色可回收项)"] --> B["② 新增时间
(越新越靠前)"]
  B --> C["③ 修改时间
(越新越靠前)"]
  C --> D["④ 大小
(越大越靠前)"]

大文件 / 大文件夹仍然按所在文件夹（位置）分组，组里最新的那一条决定这个组排多前，组内再按上面的规则排。这样既看得出文件属于哪儿，最新动过的又能浮上来。

点"大小"列头手动排

点结果表的「大小」列头，可以临时按体积排，三段循环切换：

点第几下效果
第 1 下从大到小（最占地的排最上）
第 2 下从小到大
第 3 下切回默认排序（已勾选→新增→修改→大小）

重新扫描一遍也会自动回到默认排序。

右键 / 悬停说明

🖱️ 右键 → 打开文件所在位置

在任意一行上点右键，选「📂 打开文件所在位置」：

  • 大文件 → 打开它所在文件夹并高亮选中这个文件
  • 大文件夹 → 直接打开那个文件夹
  • 回收站那行 → 打开回收站窗口

方便你先去现场看看再决定删不删。

💬 鼠标悬停 → 详细说明

把鼠标停在某一行上，会弹出一个黑底小窗，说清楚：

  • 这是什么类型、大概干嘛用的（按扩展名+所在位置猜）
  • 完整路径、精确大小
  • 创建 / 修改 / 最后打开时间、多久没动过
  • 是不是正被程序占用、删除提醒

清理与找回

  1. 勾好要删的项，点右下角红色的 🧹 清理选中项。
  2. 弹窗会告诉你要删几项、能释放多少空间，里面有"整个文件夹"的还会单独提醒。确认后开始清。
  3. 清理也在后台跑，完成后弹出结果，并自动重扫一遍方便你核对释放效果。
删错了不怕：所有删除都进回收站，去回收站右键"还原"就能找回。

遇到"文件被占用"怎么办

情况工具的处理
普通文件 / 缓存被占用会自动关掉占用它的程序再删（系统关键进程除外，那种会安全跳过）
浏览器缓存清理前会先自动关闭 Chrome / Edge，请先存好网页里没提交的内容
整个大文件夹只删到回收站、不强删、不杀进程；如果正被占用，就安全跳过、不动它（更稳）
清理前请先保存：正在编辑的文档、没提交的网页内容先存一下，免得自动关程序时丢了。

注意事项 & 常见问题

必须知道的风险点

🗂️ Windows.old：删了就无法再回退到升级前的旧系统。只有当你确定升级后一切正常、不需要退回时再删。
🗑 清空回收站：这一步是彻底删除、找不回来的。清之前确认回收站里没有还想要的东西。
🗂️ Program Files 里的程序目录：标红的那些建议走"设置 → 应用"正常卸载，别直接删目录，免得留下残余或把程序弄坏。

常见问题

Q：双击 .bat 没反应 / 一闪而过？
A：多半是没点 UAC 授权的"是"，或被杀毒软件拦了。重新双击、在弹出的授权窗口点"是"；必要时给杀毒软件加个信任。

Q：扫描怎么这么久？
A：勾了"大文件 / 大文件夹"时，工具要翻遍磁盘逐个算大小，这一步天生慢。只想快速清垃圾的话，别勾这两项，几秒就扫完。

Q：清理后空间没少多少？
A：删的东西在回收站里还占着地方。要真正释放，去把回收站清空（或在工具里勾上"回收站"一起清）。

Q：有几项提示"删不掉、已跳过"？
A：那是被系统关键进程占用、为安全没动它，属正常。重启电脑后再扫一遍通常就能清掉。
