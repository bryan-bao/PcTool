这是个啥

一个 Windows 桌面小工具，帮你找出并清理占空间的垃圾文件。用 Windows 自带的 PowerShell 写，啥都不用装，整个文件夹发给谁都能直接双击用——和你的 InstallationTools 项目一个套路、一个界面风格。

核心特点：有界面 · 绿色免安装 · 会帮你判断「能不能删 / 多久没碰过」 · 删之前一律你勾选确认，绝不自动乱删。

安全第一：普通文件删除走「回收站」，万一手滑还能找回；只有清空回收站这一项才是彻底删除（本来就是要清空它）。

界面配色、字体（微软雅黑）、蓝色主按钮，都和 InstallationTools 保持一致。扫描放后台跑，进度条转起来，界面不卡死。

三档安全标记（工具帮你判断）

不光把文件列出来，还按「公认程度 + 多久没动过」给每一项打个颜色标，省得你自己一个个琢磨：

标记什么情况默认勾选？界面提示
🟢 可放心删系统临时文件、回收站、浏览器缓存——软件生成的临时垃圾，删了没影响是 ✓「系统垃圾」「浏览器缓存」
🟡 建议确认大文件，且 ≥ 3 个月没动过——你八成早忘了，可以考虑删否「8个月没动过」
🔴 谨慎大文件，但最近 7 天还动过——提醒你别手滑删了否「最近还用过」
怎么算「多久没用」：看文件的最后修改时间，拿现在的时间一减，换算成「X 天 / X 个月」。大文件列表还能按「最久没用」排序，把占地方又早忘了的排前面。

五大功能模块

模块干啥标记
TempCleaner扫系统临时文件夹（TEMP、Windows\Temp、Prefetch 等）🟢
RecycleBin统计 / 清空回收站🟢
BrowserCache清 Chrome / Edge 缓存（不碰书签、密码、历史）🟢
LargeFiles在选中的盘上找大于 100MB 的大文件🟡/🔴
Analyzer给每一项打安全标记、算「多久没用」—

每个模块只干一件事，扫描和删除分开，返回纯数据给界面层显示——好维护、好测、出问题好查。
