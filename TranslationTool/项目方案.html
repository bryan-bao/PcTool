技术选型与理由

2026-06-12 专门调研后定案，没有特殊原因不推翻
软件窗口
pywebview

给现有网页套一个真正的程序窗口。Windows 11 自带它需要的浏览器内核（WebView2），所以软件只有约 30~60MB（同类 Electron 方案要 150MB+），且现有代码几乎一行不用改。

后台服务
Flask（沿用）

原型已经在用，稳定够用，不折腾。

翻译引擎
deep-translator

走谷歌免费接口，不要账号。万一谷歌连不上，这个库还内置必应、有道等十来个引擎，改一行代码就能切换。

语音合成
edge-tts

就是 Edge 浏览器「大声朗读」用的那套微软声音：自然度高、免费、足足 300+ 种声线可用。

打包成 exe
PyInstaller（文件夹模式）

把 Python 程序打包成普通人能直接运行的样子。特意选「文件夹模式」而非「单文件模式」：比单文件模式启动快好几秒，被杀毒软件误报的概率也低得多。

安装包
Inno Setup 6.5+

免费；官方提供简体中文语言文件，能做出全中文安装向导；桌面快捷方式、开始菜单、卸载程序全自动生成，几十行配置搞定。

被否决的路线：Electron / Tauri（要额外引入两套开发工具链，对这个小项目是杀鸡用牛刀）；Flet（等于界面推倒重写）；继续用浏览器开网页（不像个正经软件）。

注意事项与风险

🌐 必须联网才能用 翻译靠谷歌、语音靠微软，都是云端免费服务。断网时软件能打开，但翻译和生成语音会失败（界面会提示）。
🛡️ 第一次安装可能弹蓝色警告 因为没买「代码签名证书」（数百~上千元/年，自用没必要），Windows 可能弹「已保护你的电脑」。点 更多信息 → 仍要运行 即可，是正常现象不是中毒。
🚨 杀毒软件可能误报 PyInstaller 打包的程序偶尔被杀毒软件冤枉。已选的「文件夹模式」能大幅降低概率；万一还被拦，把安装目录加进杀毒软件的信任名单即可。
🔌 外部服务的小概率变动 ① 谷歌翻译在当前网络连不通时，一行代码切到必应/有道；② 微软偶尔调整语音接口，把 edge-tts 升到最新版即可恢复（旧版可能报 403）。

实测踩过的坑（2026-06-12 开发中新发现，未来改代码必读）
  • Flask 必须 threaded=True：WebView2 会长期占住连接，单线程下其他请求全被堵死（症状：连接被重置、页面打不开）。
  • 探测本地服务只能用纯 TCP（socket.create_connection），不能用 urllib 等 HTTP 库——本机开着系统代理时 127.0.0.1 的 HTTP 请求会被代理劫持（502/重置）。
  • WebView2 有 webkitSpeechRecognition 构造器但服务不可用：桌面版语音输入会静默失败，已在 onerror 里兜底（network/service-not-allowed → 隐藏按钮提示一次）。
  • 端口小概率被抢：desktop.py 已做"线程死了就换端口重试（最多 3 次）+ 失败展示错误页"。
  • TTS 文件名已加 uuid 防并发碰撞；写文件前 makedirs 兜底；devnull 兜底带 encoding="utf-8"。
阶段 3 打包检查单（2026-06-12 已照单执行完成）
  • 入口脚本先 import sys, os，然后在 import flask 之前执行 sys.stdout = sys.stdout or open(os.devnull,'w')（stderr 同理，仅在为 None 时兜底）—— 否则 --noconsole 下 Flask 一打印启动横幅就崩。
  • Flask 实例化用冻结感知路径：base = sys._MEIPASS if getattr(sys,'frozen',False) else 文件所在目录，显式传 static_folder —— 否则打包后白屏（最常见症状）。
  • audio_output 等要写入的目录：跟着程序自己走（exe 同目录），写不进去（如 Program Files）才退 %LOCALAPPDATA%；绝不能写 _MEIPASS 临时目录。本项目装用户级 D 盘目录，可直接写。
  • 冻结后必须 app.run(debug=False, use_reloader=False) —— reloader 会让 exe 无限自我复制进程。
  • 用 onedir 模式，禁用 onefile、禁用 UPX（杀软误报重灾区，onefile 还拖慢启动）。
  • 升级到最新 pyinstaller + pyinstaller-hooks-contrib（certifi / webview 官方 hooks 都在 contrib 里，edge-tts 的 SSL 证书自动打包，无需手动处理）。
  • Python 3.12 + pywebview 需要 pythonnet>=3.0；spec 里用 datas=[('static','static')] 元组加资源（避开 --add-data 分隔符平台差异）。
  • 日志写到 %LOCALAPPDATA% 下的文件（--noconsole 后看不到控制台）；调试期先打带控制台的包验证，再切 --noconsole。
阶段 4 安装包要点（2026-06-12 已执行完成，Inno Setup 在项目 tools\Inno Setup 6）
  • Inno Setup 6.5+（免费）装在项目 tools\Inno Setup 6（用户要求项目自包含）；[Languages] 用官方仓库 Unofficial 目录的 ChineseSimplified.isl（版本要和 Inno 匹配）。
  • .iss 关键段：[Setup] 固定 GUID 的 AppId、PrivilegesRequired=lowest（按用户安装免 UAC 弹窗）、WizardStyle=modern；[Files] 用 Source: "dist\翻译语音工具\*"; Flags: recursesubdirs createallsubdirs 把整个 onedir 文件夹连 _internal 全部打进去（漏子目录是最常见错误）；[Icons] 开始菜单 + 桌面（挂 Tasks: desktopicon 供勾选）；[Run] 装完可选立即启动。
  • .iss 含中文必须存成 UTF-8 带 BOM，否则安装界面乱码。
  • Win11 自带 WebView2 运行时；要兼容老 Win10 可在安装器里检测注册表并附微软 2MB 引导器静默补装（本机 Win11，暂不需要）。
