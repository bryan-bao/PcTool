一、这是什么

一个 Windows 上的图形界面小工具。把安卓安装包(.apk 文件)拖进窗口、选好手机、点一下「安装」,它就在背后通过 ADB(安卓官方调试工具)自动把 App 装进手机,不用在手机上手动点确认。

核心卖点:软件把 adb 和运行环境都打包进去了。发给别人时,对方不用装 Python、不用装 adb、不用下载任何东西,双击就能开。
项目说明
支持系统电脑端:Windows 10/11;手机端:安卓(iPhone 不支持)
连接方式USB 数据线 最稳 / WiFi 无线调试(安卓 11+)
能干啥选一个 APK,一键自动安装(覆盖安装,可更新同款 App)
暂不支持批量安装、卸载管理、文件互传、蓝牙
为啥不用蓝牙?安卓"自动安装"只能靠 adb,而 adb 只支持 USB 和 WiFi,不支持蓝牙。蓝牙只能传文件、还得手动点装,做不到全自动,所以没采用。

二、最终用户怎么用 拿到软件的人看这里

1
整个文件夹一起拷。软件是一整个文件夹(里面有 exe 和一个 _internal 文件夹)。不能只留 exe,旁边的 _internal 少了就打不开。
2
双击 APK一键安装工具.exe。
3
第一次打开,Windows 可能弹「已保护你的电脑」。点「更多信息」→「仍要运行」。不是病毒(只是没买数字签名)。
4
手机插上电脑、开好 USB 调试(见第三节)。
5
软件里点「🔄 刷新」→ 小圆点变绿、出现手机型号 → 拖入 APK → 点绿色「⬇ 安装」→ 等几秒看到「✓ 安装成功」。

三、手机端设置(开 USB 调试) 只需设一次

这是安卓系统的硬性要求,任何这类工具都绕不开。不同品牌叫法略有不同,大致流程:

1
「设置 → 关于手机」,找到「版本号」,连点 7 下,提示「已进入开发者模式」。
2
回到设置,「系统 → 开发者选项」(有的藏在「更多设置」「其他设置」里),打开「USB 调试」。
3
用数据线连电脑,手机弹「是否允许 USB 调试」时,勾「一律允许」并点确定。
电脑认不到手机? ① 换条好点的数据线(有些线只能充电不能传数据);② 确认 USB 调试已开;③ 手机的授权弹窗有没有点允许;④ 极少数手机(某些国产牌子)要装品牌 USB 驱动,去官网搜「型号 + USB 驱动」。

四、WiFi 无线连接(可选)

不想插线时用。要求:手机和电脑连同一个 WiFi,且手机安卓 11 及以上。

1
手机「开发者选项 → 无线调试」打开。
2
点进「无线调试 → 使用配对码配对设备」,记下显示的 IP 地址、端口、配对码。
3
软件切到「WiFi」标签,填入 IP、配对端口、配对码;「连接端口」填无线调试主页面显示的那个端口。
4
点「配对并连接」。连上后,拖 APK、点安装的步骤和插线时完全一样。
配对端口和连接端口是两个不同的端口:配对码页面那个是「配对端口」,无线调试主页面那个是「连接端口」。嫌麻烦直接用数据线最省事。

五、自己运行(开发 / 本地用) 需要本机装了 Python

方式一:双击 bat

双击项目里的 启动工具.bat 即可弹出窗口。

方式二:命令行

# 第一次先装依赖
pip install -r requirements.txt
# 启动
python run.py

跑测试

python -m pytest -v   # 共 17 个单元测试
开发期就算没把官方 adb 放进 platform-tools\,程序也会自动用你系统里已装的 adb,照样能跑。

六、打包成独立 exe

最省事:双击 bat

双击项目里的 打包成exe.bat,自动装 PyInstaller 并打包,完成后成品在 dist\APK一键安装工具\。

手动命令

pip install pyinstaller
python -m PyInstaller --noconfirm --clean --windowed ^
  --name "APK一键安装工具" ^
  --add-data "platform-tools;platform-tools" ^
  run.py
打包前务必先放官方 adb!把 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 放进项目的 platform-tools\ 文件夹(官方下载见第九节),否则打出来的 exe 在别人电脑上会因为没有 adb 而用不了。

想打成单个 exe 文件(可选)

把上面的 --windowed 换成 --windowed --onefile,就只生成一个 exe 文件,不用拷整个文件夹。代价:每次启动慢两三秒、更容易被杀软误报。

七、发给别人

  1. 进 dist\APK一键安装工具\ 文件夹。
  2. 把整个文件夹(连同 使用说明.html 一起)压成一个 .zip。
  3. 发给对方,对方解压后双击 exe 即用。
千万别只发单个 exe!exe 旁边的 _internal 文件夹装着 adb 和全部依赖,缺了就闪退打不开。
记得告诉对方两件事:① 第一次打开要点「更多信息 → 仍要运行」过 Windows 拦截;② 手机要先开 USB 调试。这些 使用说明.html 里都写了,让对方先看那个。

八、项目结构

FileTransferTools/ ├── apk_installer/ # 源代码 │ ├── adb_wrapper.py # 封装所有 adb 调用(找adb/列设备/配对/连接/安装) │ ├── error_messages.py # 把 adb 英文报错翻译成中文 │ ├── ui.py # 深色现代风图形界面 │ └── main.py # 程序入口 ├── tests/ # 17 个单元测试 ├── platform-tools/ # 放官方 adb.exe + 两个 dll(随程序打包) ├── docs/ # 设计文档 / 实施计划 ├── dist/ # 打包产物(发给别人的成品) ├── run.py # 启动入口 ├── 启动工具.bat # 双击本地运行(需装 Python) ├── 打包成exe.bat # 双击打包成 exe ├── requirements.txt # 依赖清单 └── README.md

代码分四块,各管一摊、互不纠缠:界面只负责显示和收集输入,真正干活(调 adb)都交给 adb_wrapper;所有命令在后台线程跑,所以装东西时界面不会卡死。

九、技术原理(想了解的看)

它到底怎么装上去的

点「安装」后,程序在后台执行这条命令:

adb -s <手机序列号> install -r "<APK路径>"

-r 表示覆盖安装(reinstall),所以能用来更新已装的同款 App。命令的输出被实时抓回来显示在日志框里,成功会有 Success,失败会带个错误码,程序把错误码翻译成中文提示。

adb 从哪来

程序优先用项目 platform-tools\ 里随附的 adb.exe;找不到才回退用系统 PATH 里的 adb。官方下载地址:

https://developer.android.com/tools/releases/platform-tools

解压后把 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 三个文件放进 platform-tools\ 即可。

为什么界面不卡

adb 命令可能要跑几秒,如果在主线程跑,窗口会卡成"转圈圈"。所以所有 adb 调用都丢到后台线程执行,结果通过一个线程安全的队列回传给界面刷新。

十、常见问题

情况原因 / 解决
双击没反应 / 闪退多半只拷了 exe、没带 _internal。把整个文件夹重拷。
弹「Windows 已保护你的电脑」正常,点「更多信息 → 仍要运行」。没买签名而已。
杀毒软件报警PyInstaller 打的 exe 偶被误报,加白名单即可。
刷新后圆点不变绿 / 找不到手机检查数据线、USB 调试是否开、授权弹窗是否点允许;个别手机要装 USB 驱动。
圆点黄色检测到手机但没授权,手机上点「允许此电脑调试」。
签名不一致,请先卸载手机上已有同名但来源不同的 App,先卸载旧的再装。
不能安装更低版本手机上版本更新,先卸载手机上的再装。
WiFi 连不上确认手机电脑同一 WiFi、安卓 11+、配对端口和连接端口没填反。
开发时 ModuleNotFoundError没装依赖,先 pip install -r requirements.txt。
排查万能招:看软件底部日志框那行中文提示,基本一看就知道卡在哪。
