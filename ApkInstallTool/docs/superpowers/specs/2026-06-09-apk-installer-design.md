# APK 一键安装工具 — 设计文档

- 日期:2026-06-09
- 项目目录:`E:\超-工具\FileTransferTools`
- 平台:Windows 11

## 1. 背景与目标

做一个 Windows 上的**图形界面小工具**,让用户把 APK 文件拖进去、选好手机、点一下"安装",
就能**自动把 APK 推送到安卓手机并完成安装**,全程不用在手机上手动点确认。

本质:给 Android 官方调试工具 `ADB`(Android Debug Bridge,安卓调试桥)套一个友好的图形外壳。

### 关键技术现实(决定方案的前提)

在安卓上**自动安装** APK 只能通过 `ADB` 完成,而 ADB 只支持两种传输通道:

1. **USB 数据线**
2. **WiFi(同一局域网,无线调试)**

ADB **不支持蓝牙**。纯蓝牙只能"传文件",安装仍需用户在手机上手动点击,无法做到自动安装。
因此本工具**放弃蓝牙方案**,采用 ADB(USB / WiFi),以满足"全自动安装"这一核心诉求。

## 2. 技术选型

- 语言:**Python**
- 界面库:**CustomTkinter**(现代化外观的 Tkinter 封装)
- 安装引擎:**ADB**(打包随附,见第 3 节)
- 后台执行:`subprocess` + 独立线程(避免界面卡死)

## 3. ADB 的获取方式(已确认采用 A 方案)

**方案 A:把官方 platform-tools 里的 `adb.exe` 随程序打包。**

- 用户下载即用,无需自行安装任何环境,双击即可运行。
- 代价:软件体积增大数 MB(可接受)。
- 程序启动时优先使用随附的 `adb.exe`(放在程序目录下,例如 `./platform-tools/adb.exe`);
  找不到时再回退尝试系统 PATH 中的 `adb`。

## 4. 连接方式(USB + WiFi 都支持)

界面通过标签页切换两种连接方式:

### 4.1 USB
- 用户用数据线连接手机,并在手机上开启「开发者选项 → USB 调试」。
- 工具调用 `adb devices` 检测设备。
- 若检测到设备状态为 `unauthorized`,提示用户在手机上点击「允许此电脑调试」。

### 4.2 WiFi(无线调试)
- 适用于安卓 11+ 的「无线调试」配对流程。
- 界面提供输入框:手机 IP、端口、配对码(pairing code)。
- 配对:`adb pair <ip>:<pair_port> <pairing_code>`
- 连接:`adb connect <ip>:<connect_port>`
- 提示用户在手机「开发者选项 → 无线调试」里查看 IP、端口与配对码。

## 5. 界面布局

单一主窗口,从上到下:

1. **连接方式区**:USB / WiFi 两个标签页。
2. **设备区**:
   - 「刷新设备」按钮 → 列出当前已连接手机(显示型号/序列号)。
   - 多台设备时可选择目标设备。
   - 未检测到设备时,根据当前标签页给出对应的排查提示。
3. **APK 选择区**:
   - 一个大拖拽框,**支持把 APK 文件直接拖进来**。
   - 也提供「浏览…」按钮通过文件对话框选择。
4. **操作区**:
   - 「安装」按钮。
   - 下方**日志框**,实时显示进度与结果。

## 6. 数据流(点击"安装"之后)

1. 校验:已选设备 + 已选有效 `.apk` 文件。
2. 后台线程执行:`adb -s <设备序列号> install -r "<apk路径>"`
   - `-r` 表示覆盖安装(reinstall),允许更新已安装的同包名应用。
3. 实时抓取命令输出,逐行显示到日志框。
4. 结果处理:
   - 成功(输出含 `Success`):提示「安装成功」。
   - 失败:把常见错误码翻译成大白话,例如:
     - `INSTALL_FAILED_UPDATE_INCOMPATIBLE` → 签名不一致,需先卸载旧版本。
     - `INSTALL_FAILED_VERSION_DOWNGRADE` → 不能装更低版本。
     - 设备未授权 / 未连接 → 提示检查连接与调试授权。

## 7. 并发与稳定性

- 所有 ADB 调用放在**后台线程**执行,通过线程安全的方式更新界面,避免主界面卡死转圈。
- 安装进行中,「安装」按钮置灰,防止重复点击。

## 8. 模块划分(便于独立理解与测试)

- `adb_wrapper`:封装所有 ADB 调用(找 adb、列设备、pair、connect、install),
  对外提供清晰函数,返回结构化结果(成功/失败 + 原始输出)。不依赖界面。
- `ui`:CustomTkinter 界面,只负责展示与收集用户输入,通过调用 `adb_wrapper` 干活。
- `error_messages`:把 ADB 错误码/输出翻译成中文大白话提示。
- `main`:程序入口,组装以上模块。

## 9. 范围控制(YAGNI — 本期不做)

明确**不做**:
- 批量安装多个 APK
- 卸载 / 应用管理 / 应用列表
- 文件互传
- 蓝牙连接(无法满足自动安装)

先把「单个 APK 一键自动安装(USB + WiFi)」这条主线跑通,后续再按需扩展。

## 10. 成功标准

- 用户在 Windows 上双击运行程序(无需预装 Python 之外的环境,最终可打包成 exe)。
- USB 或 WiFi 连上手机后,拖入一个 APK,点「安装」,几秒内手机上自动装好该应用。
- 失败时能看到一句听得懂的中文原因提示。
