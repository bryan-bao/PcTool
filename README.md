# PcTool —— Windows 实用小工具合集

这是一组面向 Windows 的桌面实用小工具，每个工具都是一个独立子目录、可单独使用。
本仓库只收录**源码**部分；构建产物（`venv/`、`dist/`、`build/`、`node_modules/` 等）、
打包好的 exe/安装包、系统镜像 ISO、音视频等大文件均不纳入（见根目录 `.gitignore`）。

## 工具一览

| 工具目录 | 是什么 | 技术栈 |
| --- | --- | --- |
| [ApkInstallTool](#apkinstalltool--apk-一键安装工具) | APK 一键安装工具：把 APK 拖进窗口，选好手机点一下，通过 ADB 自动装到安卓手机（支持 USB / WiFi 无线调试） | Python |
| [FileTransferTool](#filetransfertool--局域网文件传输工具) | 局域网文件传输工具：同一 WiFi 下电脑↔手机、电脑↔电脑互传文件，带限速、实时速度、断点续传、接收确认 | Go + Wails |

## ApkInstallTool —— APK 一键安装工具

Windows 图形界面工具：把 APK 拖进窗口，选好手机，点一下，通过 ADB 自动安装到安卓手机。
支持 USB 数据线和 WiFi 无线调试两种连接方式。打包成 exe 后别人无需装 Python、也无需装 adb。

- 本地运行：`pip install -r requirements.txt` 然后 `python run.py`（或双击 `启动工具.bat`）
- 详细说明见该目录下 `README.md` 与 `使用文档.html`

## FileTransferTool —— 局域网文件传输工具

电脑和手机、电脑和电脑之间，在同一个 WiFi/路由器下互传文件。带限速、实时速度、断点续传、接收确认。
手机扫窗口里的二维码即可上传，电脑互发支持整个文件夹、还能生成固定下载链接发给别人。打包后是单个 exe，免安装。

- 开发：`wails dev`；打包：`wails build`；测试：`go test ./...`
- 详细说明见该目录下 `README.md`

## InstallationTools —— 一键重装 / 桌面还原工具

PowerShell + WPF 写的装机辅助工具：系统镜像装机（版本分路）、桌面文件备份与还原、系统优化等。

- 启动：双击 `一键启动.bat`（会请求管理员权限）
- 设计文档见该目录 `docs/`
- 注：系统镜像 ISO、备份文件、官方下载工具等大文件未纳入仓库

## TranslationTool —— 翻译·语音小工具

集翻译、截图翻译、划词翻译、文字转语音于一体的桌面小工具：

- **翻译**：支持中（简/繁）、英、日、韩、法、德、西、俄等 14 种语言互译
- **截图翻译**：快捷键框选屏幕文字，本机 OCR 识别后翻译，可原位覆盖（像汉化补丁）
- **划词翻译**：任意软件里划选文字即可弹出译文
- **语音**：翻译结果朗读、文字转语音生成 MP3
- 详细说明见该目录 `使用说明.txt` 与 `CLAUDE.md`

## 磁盘清理工具

Windows 桌面磁盘清理工具，PowerShell + WPF 编写，绿色免安装：

- 系统临时文件、回收站、浏览器缓存（Chrome / Edge）清理
- 大文件查找（带「多久没用」提示）
- 三档安全标记（🟢 可放心删 / 🟡 建议确认 / 🔴 谨慎），删除走「扫描 → 勾选 → 确认」
- 启动：双击 `一键启动.bat`（会请求管理员权限）
